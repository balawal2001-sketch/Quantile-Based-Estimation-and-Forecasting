# Quantile-Based-Estimation-and-Forecasting

Project Overview

This comprehensive econometric research project investigates robust estimation techniques in linear regression, with a specific focus on quantile-based methods as alternatives to Ordinary Least Squares (OLS). The study is divided into two main components:

Part A: Monte Carlo Simulation Study

Evaluates the performance of three quantile-based slope estimators under various error distributions:

Criterion 1: Symmetric weights (0.25, 0.50, 0.25)
Criterion 2: Koenker-type optimal weights (0.3240, 0.3522, 0.3239)
CQR (Composite Quantile Regression): Simple average of quantile estimates

Part B: Empirical Applications

CO₂ Emissions Forecasting: Monthly time series analysis of seasonally adjusted CO₂ emissions
Wage Determinants Analysis: Using the ISLR Wage dataset to examine heterogeneous effects across income distribution
